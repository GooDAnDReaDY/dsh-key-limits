# @goodandready-private/dsh-key-limits

Веб-плагин для DeepSeek Harness (DSH): мониторинг лимитов квот, тарифных планов и балансов API-ключей внешних нейросетевых провайдеров.

[English Documentation (README.md)](./README.md) | [中文文档 (README.zh.md)](./README.zh.md)

---

## Обзор

`dsh-key-limits` создан для удобного и ненавязчивого контроля остатка квот и балансов подписок непосредственно в веб-интерфейсе DSH. Плагин намеренно исключает тяжеловесный бухгалтерский учёт, детализацию расходов, сбор исторических графиков и сложные финансовые сводки, фокусируясь только на актуальных лимитах.

### Ключевые возможности

- **Плавающий чип (`FloatChip`)**: свободно перемещаемый индикатор общего состояния всех подписок (наименьший оставшийся процент квоты либо количество настроенных ключей) с защитой от вылета за границы экрана (`viewport clamping`) и сохранением координат в `localStorage`.
- **Интеграция со строкой ввода (`ActiveKeyButton`)**: кнопка в панели ввода сообщений активного чата (`conversation.composer.bar`, приоритет 10), отображающая оставшуюся квоту или баланс подписки, привязанной к модели текущего диалога.
- **Карточка в настройках (`KeyLimitsPluginCard`)**: стандартная сворачиваемая карточка в разделе `Настройки → Плагины`, позволяющая добавлять, редактировать, принудительно опрашивать и удалять ключи, а также проверять и устанавливать обновления в один клик.
- **Сетевая надёжность и изоляция сбоев**: все внешние запросы к провайдерам защищены таймаутами 12 секунд (`AbortSignal.timeout`), сетевые ошибки помечают данные как `stale` без поломки интерфейса, а запись на диск выполняется строго атомарно (`.tmp` + `renameSync`).
- **One-Click Updater**: встроенный безопасный локальный модуль обновления (`loopback-only`), позволяющий обновлять плагин прямо из настроек DSH.

## Пользовательские поверхности

| Поверхность | Расположение | Поведение и функционал |
|-------------|--------------|------------------------|
| **Плавающий чип** | Фиксированный оверлей браузера | Показывает наименьший остаток квоты среди всех ключей или число ключей. Перетаскивается мышью/тачем. Клик открывает окно **со всеми подписками и окнами квот**. |
| **Кнопка в строке ввода** | Панель ввода сообщений (`conversation.composer.bar`) | Отображает статус/квоту подписки активной сессии. Клик открывает детальное окно **только активного ключа**. |
| **Карточка настроек** | `Настройки → Плагины → Лимиты ключей` | Управление каталогом хранения данных, частотой опроса, добавление/удаление ключей провайдеров и кнопка проверки/установки обновлений. |

## Архитектура и хранилище

### Структура каталога данных

Данные сохраняются в каталоге `~/.dsh/storages/dsh-key-limits/`:
- `subs.json`: реестр подписок и кэш карточек квот. Секретные ключи передаются в защищённую службу `credentials` ядра DSH; файл `subs.json` хранит только безопасные идентификаторы `credentialRef`.
- Атомарность записи: при любом изменении файл сначала пишется во временный файл со случайным суффиксом, после чего атомарно подменяется системным вызовом `renameSync`.

### Изоляция стилей

Стили плагина оформлены со стандартным маркером принадлежности:
```html
<style data-dsh-plugin="dsh-key-limits">
  /* изолированные css-правила */
</style>
```
Тег монтируется и демонтируется через `ctx.effect`, предотвращая накопление дубликатов в `document.head` при перезапусках.

## Установка

Установка одобренной версии пакета:

```bash
dsh plugin --profile web add @goodandready-private/dsh-key-limits@0.1.6
```

> **Важно**: В продакшене разрешено использовать только опубликованный пакет из настроенного registry. Установка напрямую из рабочей копии или worktree запрещена.
